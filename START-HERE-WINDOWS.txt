DOTA ASCENT - YOUR PERSONAL DOTA 2 COACH

1. Install Python 3.10 or newer from:
   https://www.python.org/downloads/windows/
   Tick "Add Python to PATH" during installation.

2. Right-click the downloaded ZIP -> Extract All.
   Open the extracted folder containing run.bat.

3. Double-click run.bat. Keep its console window open.
   Your browser should open automatically.
   If it does not, type http://127.0.0.1:8765 in your browser.

4. In Dota 2, enable Settings -> Social -> Expose Public Match Data.
   Your Dota friend ID (314758455) is already filled in.
   Choose the role you played, then click Analyze my matches.
   If history is empty, sign in to OpenDota and play new ranked games.
   Analyze always checks fresh history. Older hidden games may stay missing.
   The button no longer jumps down the page: results appear below it.
   If history is empty, use Check OpenDota again or review a match by ID.

5. Pick ONE focus for your next five games. Use Match review to examine
   parsed events and your in-game replay to understand decisions.
   Sample dashboard data is invented and clearly labeled.

TO STOP: Close the console window or press Ctrl+C in it.
TO START AGAIN: Double-click run.bat.
If it is already running, this reopens its browser. If its usual port is
busy, it can use another port; the console prints the correct address.

OPTIONAL AI CHAT:
The normal dashboard works without it. For a local AI conversation:
- Install and start Ollama: https://ollama.com/download/windows
- Open Command Prompt and run: ollama pull llama3.2:3b
- Load a report, scroll to Ask your coach, and ask a question.
The model is a few GB and needs free disk space and RAM.
AI can be wrong; check its claims against your evidence and replay.

OPTIONAL LIVE SCREEN COACH:
- Start Ollama, then double-click setup-live.bat to download gemma3:4b.
- Keep Ollama open. Start the coach with run.bat in Chrome or Edge.
- Open Live screen coach. Enter your current hero and role.
- Click Choose Dota window, select Dota, and verify the preview.
- Click Analyze one snapshot, or explicitly start periodic checks.
- Stop sharing ends capture. No frame is sent just from choosing a source.
- Local spoken advice is optional. Capture and inference can be delayed.
This uses selected snapshots, not continuous game understanding or hidden
enemy information. It needs no OpenDota key or public match history.
Use borderless window mode if the preview is black; keep the coach tab open.
The app saves no screen recordings or frames. An already-started model
analysis may finish locally after Stop, but its reply will be ignored.

No paid API key, Steam password, or programming commands are required
for the dashboard. No Python package installation is required.

IF YOU HAVE AN OPENDOTA API KEY:
- Regenerate any key previously shared in chat or a code comment.
- Close all running coach consoles.
- Double-click set-api-key.bat in this folder.
- At OpenDota API key:, paste your replacement key and press Enter.
  Characters stay hidden. Paste it again when asked and press Enter.
- When it says saved, press any key, then double-click run.bat.
- The account panel says OpenDota API key configured. Click Analyze.
Do not put the key into either .bat file or into a chat message.
The key is stored in .local/opendota-api-key.json, a plain-text local file.
Do not share the .local folder. Your OpenDota plan's API usage applies.
The key does not guarantee availability of hidden games or old replays.

Read README.md for troubleshooting, data limitations and developer tests.
This app uses OpenDota parsed JSON, not raw .dem replay files.
It cannot promise Divine or automatically prove why a game was lost.
